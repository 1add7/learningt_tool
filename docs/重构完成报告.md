## 代码质量提升

### 代码量减少
- **后端**：减少 23%（208 行 → 160 行）
- **前端 Store**：减少 36%（277 行 → 177 行）
- **前端组件**：减少 17%（1245 行 → 1028 行）
- **总体**：减少约 **25%**

### 职责分离
- **后端**：配置管理、消息构建、API 调用逻辑分离
- **前端**：主题、聊天、导出、上下文、挂载模式逻辑分离
- **Store**：只负责状态管理，不包含业务逻辑

### 可测试性提升
- 每个 Composable 可以独立测试
- 工具函数可以独立测试
- 业务逻辑与 UI 分离，便于编写单元测试

### 可维护性提升
- 每个模块职责单一，易于理解
- 代码定位更加容易
- 新功能开发更加容易
