# 系统性重构实施计划

## 重构目标

根据重构评估报告，本次重构旨在：
1. 简化后端 LLM 服务代码结构
2. 优化前端代码组织，实现高内聚低耦合
3. 提升代码可维护性、可测试性和复用性

## 重构范围

### 后端重构
- `server/src/services/llmService.ts` - 简化 LLM 服务代码

### 前端重构
- `client/src/views/HomeView.vue` - 拆分职责，减少代码量
- `client/src/stores/knowledge.ts` - 简化 Store 职责
- 新增 Composables 目录和文件
- 新增工具函数文件

## 重构步骤

- **文件**：`server/src/services/llmService.ts`

## 风险控制

### 低风险改动
- 后端 LLM 服务重构（独立模块）
- 工具函数提取（纯函数，易于测试）

### 中风险改动
- Composables 提取（需要修改组件引用）
- Store 简化（影响多个组件）

### 高风险改动
- HomeView.vue 重构（核心组件，影响面大）

### 风险缓解措施
1. **渐进式重构**：每次只重构一个模块
2. **保留原代码**：重构前创建备份分支
3. **充分测试**：每个阶段完成后进行测试
4. **回滚机制**：出现问题立即回滚
